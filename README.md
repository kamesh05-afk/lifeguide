# LifeGuide — bilingual emergency guide website

## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a new public repository on GitHub (for example, `lifeguide`).
2. Choose **Add file → Upload files** and upload `index.html`.
3. Commit the file to the `main` branch.
4. Open **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub to publish the site. The Pages URL will appear on that settings screen.

This is a starter guide, not an emergency service. Verify all advice and official links before public launch. Do not collect sensitive personal data.
